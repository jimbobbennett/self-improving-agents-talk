# Original Thanksgiving Chatbot

This folder is the committed baseline app snapshot for the self-improving agents talk. It contains the chat UI, original agent, tools, fixtures, and AX configuration as they stand at this stage.

Run the app from this directory:

```sh
npm install
npm start
```

Set `OPENAI_API_KEY` to run the agent. Set `ARIZE_API_KEY`, `ARIZE_SPACE_ID`, and `ARIZE_PROJECT_NAME=thanksgiving-food-lore-demo` to send traces to Arize AX.
